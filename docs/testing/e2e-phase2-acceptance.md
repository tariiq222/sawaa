تمت أيضًا مطابقة دفعة التشغيل النهائي مباشرة مع المزود وحفظ إثبات مختصر بلا مفاتيح أو بيانات بطاقة. نسخة الأدلة والإيصالات محفوظة في `/Users/tariq/.codex/reports/sawaa-e2e-phase2-20261008/final/` وإثبات المزود في `provider-receipt-final.json` بمجلد التقرير نفسه. التشغيل التجريبي الأول وأدلته محفوظة في `initial/`.

- واجهة الدفع الإلكتروني داخل التطبيق، Apple Pay، أو checkout الموقع المستضاف، أو وصول webhook للمحلي. SW-P01 الحالي عقد Native API + Sandbox + reconcile فقط.

- DIRECT، تعدد الخدمات/الممارسين، عزل عميل آخر، منافسة المواعيد، الدفع الفاشل/المنتهي، الباقات، الإلغاء والاسترداد، أو وصول الإشعارات.
- بوابة Playwright smoke الكاملة لم تُعد هنا؛ لم يتغير كود الباك أو لوحة التحكم، وSW-D02 هو دليل الواجهة الحي لهذه الحزمة.
