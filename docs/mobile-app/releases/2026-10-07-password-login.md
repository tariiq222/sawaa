# الدخول بكلمة المرور أو الرمز — 2026-10-07

## السلوك

- شاشة الدخول تبدأ بكلمة المرور، مع تبويب بديل لرمز التحقق. البريد أو الجوال وكلمة المرور يؤديان مباشرة إلى جلسة عميل دون رمز إضافي.
- إرسال رمز البريد يبدأ من شاشة الدخول نفسها دون إعادة إدخال البريد أو الضغط على إرسال مرة أخرى. مسار تسجيل العميل الجديد وإثبات الجوال باقٍ.
- إنشاء أو استعادة كلمة المرور اختياري بالبريد أو الجوال، بعد رمز الاستعادة ذي الأربعة أرقام. رمز دخول البريد المنفصل يبقى ستة أرقام. سياسة كلمة المرور: 8–200 حرف، وحرف إنجليزي كبير ورقم على الأقل.
- يُحفظ سياق الحجز والوجهة بعد الدخول. كلمة المرور لا تُحفظ، وتُلغي مغادرة الشاشة أو تبديل الطريقة نتيجة طلب دخول متأخر.
- المسار الجديد `POST /mobile/auth/password-login` يعيد `sessionKind=client` ورموز جلسة العميل الأصلية. يرفض الحسابات الموقوفة والمحذوفة والموظفين وتعارضات الربط، ويحافظ على حدود المحاولات وتجديد الجلسة. مسار Apple للمراجعة لم يتغير.
- إنشاء/استعادة كلمة المرور يثبت فقط وسيلة الاتصال التي أثبت الرمز ملكيتها، ويحافظ على إبطال الجلسات القديمة ومنع إعادة استخدام إثبات الاستعادة. البريد القديم الموثق على User يمكنه الوصول إلى Client المرتبط دون إضافة بريد جديد إلى سجل العميل.

## التحقق

اكتمل التحقق المحلي:

- الخادم: 899 مجموعة ناجحة، 8811 اختبارًا ناجحًا وحالة واحدة متجاوزة؛ `pnpm --filter=backend test --runInBand` بمتغيرات البيئة المحلية المعزولة. نجح `pnpm --filter=backend run build`.
- الجوال: 188 مجموعة و1343 اختبارًا ناجحًا؛ `pnpm --dir apps/mobile test --runInBand`. نجح فحص الأنواع؛ lint بلا أخطاء مع 5 تحذيرات سابقة خارج التغيير.
- HTTP/PostgreSQL: 64 اختبار مصادقة مرتبطًا ناجحًا، ثم 7 اختبارات المسار الجديد ناجحة تشمل بريدًا/جوالًا، تجديد الجلسة، الحساب القديم، رفض الإيقاف والقفل، منع إعادة استخدام الإثبات، ورفض تغير الجوال أثناء اشتقاق كلمة المرور. إرسالات البريد والجوال معزولة بمحاكيات التسليم.
- Dashboard smoke: 41 ناجحًا وحالة المحادثات متجاوزة وفق الإعداد. فشل الإعداد الأول بسبب اتصال لوحة محلية قديمة ثم CORS للمنفذ المعزول؛ نجح التشغيل بعد ضبط عنوان البيئة المحلية.
- جُدد OpenAPI وأنواع لوحة التحكم بـ`pnpm openapi:sync`. نجحت فحوص انحراف عملاء API و`git diff --check`. عميل API اليدوي لا يستهلك المسار الأصلي الجديد؛ الخدمة المخصصة في الجوال تستهلكه مباشرة.
- المراجعة المستقلة: عولج تعارض ترجمة زر الدخول ودعم استعادة البريد الموثق على User فقط. عولج اختلاف طول رمز الاستعادة (4 أرقام) عن رمز الدخول بالبريد (6)، وأضيفت إعادة التحقق من الهوية تحت قفل الصف قبل تغيير كلمة المرور.
- قياس استهلاك المهمة غير مكتمل بسبب تعطل ربط المشاركين في سجل القياس؛ لا ادعاء لاستهلاك كلي أو وفورات. الأدلة المحلية في `/Users/tariq/.codex/release-evidence/2026-10-07-password-login/`؛ تشمل اختبارات RED/GREEN، اختبار HTTP وقاعدة PostgreSQL معزولة، المراجعة المستقلة وفحوص الخادم والجوال ولوحة التحكم. لا إرسال بريد أو SMS حقيقي في الاختبارات، ولا اختبار على جهاز فعلي.
