# تطبيق سواء — سجل العمل والإصدار

هذا المجلد مرجع تحديثات تطبيق الجوال وتجهيز App Store. آخر تحديث: 2026-09-27. دوّن كل تغيير جديد في سجل مؤرخ، وحدّث [تسلسل البناء والتسليم](runbook.md) إذا تغيرت الخطوات. لا يعني اكتمال البناء اكتمال الإطلاق.

| الطبقة | الحالة المثبتة |
|---|---|
| المصدر المحلي | أُنشئ البناء 9 من working tree قبل حفظ التعديلات في commit محلي؛ لم يُدفع الكود |
| الفحوص المحلية | قبل البناء 9: 118 مجموعة / 724 اختبار جوال ناجح، typecheck ناجح، lint دون أخطاء مع 5 تحذيرات في ملفات أخرى؛ التفاصيل وحدودها في السجل المؤرخ |
| البناء الموقّع | EAS `1.0.0 (9)` مكتمل، وIPA مطابق للمعرّف والإصدار |
| Apple / TestFlight | معالجة البناء 9 `VALID` و`APP_STORE_ELIGIBLE`، وإقرار التشفير محفوظ، وهو مرتبط بمجموعة Sawaa Internal ذات مختبر واحد؛ تثبيته واختباره على جهاز فعلي غير متحققين |
| النشر العام | لم يُرسل البناء 9 إلى App Review ولم يُنشر للعموم |
