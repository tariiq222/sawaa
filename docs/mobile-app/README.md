# تطبيق سواء — سجل العمل والإصدار

هذا المجلد مرجع تحديثات تطبيق الجوال وتجهيز App Store. آخر تحديث: 2026-09-24. لا يعني اكتمال البناء اكتمال الإطلاق.

| الطبقة | الحالة المثبتة |
|---|---|
| المصدر المحلي | تصحيحات IBM العربية وRTL والعرض؛ تغييرات الإصدار غير ملتزمة في Git عند التوثيق |
| الفحوص المحلية | الجوال 54 مجموعة / 294 اختبارًا ناجحًا؛ الخادم 846 مجموعة / 7838 اختبارًا ناجحًا واختبار واحد متجاوز؛ TypeScript وlint ناجحان |
| المحاكي | مراجعة عربية/إنجليزية ولقطات iPhone وiPad ببيانات اصطناعية |
| البناء الموقّع | الإصدار 1.0.0 (5) موقّع؛ يسبق إضافة دخول الحساب التجريبي ويحتاج بديلًا |
| App Store Connect | مسودة عربية وصور محفوظة: خمس لكل جهاز |
| Apple / TestFlight | لم يثبت رفع البناء أو معالجته أو إمكانية تثبيته |
| الحساب التجريبي | أُنشئ واختُبر محليًا فقط؛ لم يُفعّل في الإنتاج |
| النشر العام | لم يتم؛ حقول وقرارات ومراجعة حساب تجريبي ما زالت مفتوحة |
